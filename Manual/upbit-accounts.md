# Upbit 멀티 계정 관리

## 개요

여러 Upbit 계정을 등록하고 계정당 하나의 자동매매 세션을 운영할 수 있습니다.

## 계정 등록

1. 좌측 사이드바에서 **Accounts** 클릭
2. "+ 계정 추가" 클릭
3. 라벨(예: "메인"), Access Key, Secret Key 입력
4. "추가" 클릭 → 자동으로 Upbit 연결 테스트 실행
   - 성공: 카드 목록에 추가됨
   - 실패: 키링/DB 모두 롤백됨, 에러 메시지 표시

## 세션 시작

1. **Live Trading** 페이지에서 "+ 새 세션"
2. **Upbit 계정** 드롭다운에서 선택
   - 이미 실행 중인 real 세션이 있는 계정은 선택 불가
   - 비활성화된 계정도 선택 불가
3. 프리셋, 라벨, 초기 자본 입력 후 시작

## 안전장치

- **1 계정 = 1 running real 세션**: DB 부분 유니크 인덱스가 강제
- **paper 세션**은 같은 계정에서 N개 공존 가능 (실주문 없음)
- **계정 점유 = running real 세션만**: paper 세션은 키·자금을 쓰지 않으므로 계정을 잠그지 않는다.
  실행 중 real 세션을 paper로 되돌리면 계정 연결은 보존되지만 점유는 해제되어, 다른 새 세션을
  같은 계정에 real 승급할 수 있다.
- **삭제/키수정/비활성 가드**: 실행 중 **real** 세션이 있는 계정만 변경/삭제 불가 (paper는 허용)
- **연결 테스트 실패 시 자동 롤백**: 잘못된 키 입력으로 인한 잔존 상태 없음

## 계정별 Discord webhook

여러 사용자가 같은 화면을 시청하는 환경에서, **계정마다 다른 Discord 채널로** 알림을 보낼 수 있습니다.

### 동작
| 계정 webhook 설정 | 동작 |
|--------------------|------|
| 비어 있음(NULL) | Settings의 글로벌 Discord webhook을 fallback으로 사용 |
| URL 입력됨 | 글로벌 설정 대신 이 계정 webhook으로 전송 |

- 텔레그램/FCM은 이 분기에 영향받지 않습니다(Discord embed 경로만 override됨).
- 카드에 `Discord: 계정 전용 채널` 또는 `Discord: 글로벌 fallback` 배지로 표시됩니다.

### 편집
1. **Accounts** 페이지에서 계정의 `Edit` 클릭
2. `Discord` 탭 선택
3. webhook URL 입력 후 저장
   - 입력값을 **비우고 저장하면** NULL로 정규화되어 글로벌 fallback으로 돌아갑니다.
4. 키 교체와 달리 webhook 변경은 running 세션 가드 없이 즉시 적용 (다음 체결부터 새 채널로 전송).

### 테스트
각 계정 카드의 `Discord` 버튼으로 라우팅을 검증할 수 있습니다.

- 단일 테스트 메시지를 실제 라우팅 정책(계정 webhook → 글로벌 fallback)을 그대로 거쳐 전송합니다.
- 결과 라인에 어디로 갔는지 명시됩니다:
  - `✓ '<라벨>' — 계정 전용 채널로 전송 완료`
  - `✓ '<라벨>' — 계정 webhook 없어 글로벌 채널로 전송됨`
  - `✗ Discord 실패: …` (webhook 0건이면 두 곳 모두 미설정 안내)
- Discord에 도착하는 메시지 형식: `[<라벨>] BTC Trader Discord 테스트 — 계정 전용 채널` 또는 `… — 글로벌 fallback`.

이 테스트는 `notification_configs.enabled=1`인 글로벌 설정만 fallback으로 인정합니다(라이브 알림과 동일 정책).

## 마이그레이션 (기존 사용자)

- 첫 부팅 시 기존 단일 키가 자동으로 `account_id=1, label='기본'` 계정으로 흡수됨
- 기존 실행 중인 세션은 이 계정에 자동 연결
- 환경변수(`UPBIT_ACCESS_KEY`/`UPBIT_SECRET_KEY`)는 첫 부팅 시 1회만 참조 — 이후 무시
